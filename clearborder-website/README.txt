Tariffmark website
===================

To view: keep these files together in one folder and double-click index.html.
It opens in any modern browser (Chrome, Edge, Safari, Firefox). No installation
or server is needed.

Files
  index.html                    Page content and structure
  styles.css                    Colours, typography and layout
  script.js                     Interactive parts (example determinations,
                                tabs, pricing toggle, plan calculator, form)
  assets/naveen-nandakumar.jpg  Founder photo (replace with a real photo,
                                keeping the same file name)

Notes
  - Fonts (Archivo, IBM Plex Mono) load from Google Fonts when online;
    offline, the page falls back to system fonts.
  - The "Register interest" form checks the fields but does not send
    anything. Connect it to a form service or backend before going live.
  - Colours are defined once at the top of styles.css (the :root block).
